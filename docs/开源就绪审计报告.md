## 一、架构与执行流程串联（现状确认）

**启动序列**：`IrisLiteApplication` → YamlSchemaProvider 加载 classpath 基线（缺失容错为 0）+ 外部目录覆盖（mtime 热载）→ SchemaManager 原子替换 → 一致性 repair（T12，JDBC 对源库清漂移）→ CDC 消费组建立（136 路源，XREADGROUP BLOCK 轮询）→ FT 索引确保（FT.INFO 就绪校验）→ MCP 工具索引构建（838 候选，指纹对账 + tools/list_changed）→ 控制台身份探测。

**查询链路**（三层装饰器，`DefaultEntityQueryService`）：鉴权裁剪（授权∩字段约束取交集，fail-closed，tags 由 request attribute 注入不可伪造）→ 实体语义缓存（T19 版本围栏：依赖实体版本不符即 miss/stale）→ 实体精确缓存 → Query Engine 索引查询（TAG/NUMERIC/TEXT，分页下推 LIMIT）。MCP on-demand 两跳（`search_entity_tools` → `call_entity_tool`）与 REST 落到同一链路。

**CDC 投影**（`DefaultChangeEventHandler`）：Debezium JSON → Stream → 投影 hash/JSON + FT 索引回填 + 版本 bump（`iris:{ns}:ver:{entity}`）+ 缓存失效（可开关）。重试走 PEL reclaim（~6s/条），**无死信队列**——毒事件会无限重试（见 P1-6）。

**记忆/LLM 缓存**：工作记忆（TTL + Lua 原子 append + wm- 语义索引，多轮上下文已读回注入）→ 渐进摘要（8000 字符/保留 40%，`SessionSummarizationService`）→ 异步抽取晋升长期记忆（trigger-every 6 条，去重 KNN 0.80，ownerId 隔离）。LLM 缓存：精确 promptHash → KNN 0.85 召回 → 槽位一致性校验 → bge-reranker 精判 0.50 门 → 版本围栏。

**模块边界**（抽查验证通过）：api 不碰 Redis、application 无 Redis 命令、cdc 只消费不查询、key 集中 KeyStrategy、LlmClient/OpenAI 兼容实现真实存在。依赖全部公开仓库（无 SNAPSHOT 第三方依赖、无 system scope、maven wrapper 为 only-script 可自助下载）。

## 四、单机部署「开箱即用」补全方案

**目标动线**（README 快速开始重构为此四步，全程不超过 10 分钟）：

```
1. docker compose up -d                 # 基础设施（已具备，compose 本身完整可用）
2. ./mvnw -DskipTests clean package     # 已具备
3. java -jar api/target/iris-lite-api-*.jar
                                        # 零配置起步：无模型 → 自动降级 hashing + WARN 指引；
                                        # 默认 profile 只挂 2 个演示实体
4. 打开控制台 → 点演示场景 → 看到真数据 → 再按需启用 onnx/全量数据集
```

对应改造：

1. **配置拆分**：
   - `application.yml` 瘦身为最小起步：2 个 CDC source（MySQL `demo_customer` + PG `product`，与现有 PG init 种子对齐）；schema/model 路径改**相对路径** `deploy/models/...`、`deploy/schema`；
   - 136 路全量配置迁到 `application-ecomm.yml`（激活方式 `--spring.profiles.active=ecomm`），README 标注「完整电商数据集演示」。
2. **补 MySQL 演示数据**：新增 `deploy/mysql/init/002-demo-tables.sql`（最小起步 2 表的建表 + 种子；可选再做一份 135 表数据集的导入脚本，或提供「Schema yml ↔ 建表 SQL」对齐说明）。
3. **模型体验优化**：OnnxEmbedder/Reranker 模型缺失时，报错文案给出两条路（下载见 deploy/models/README.md / `iris.embedder.type=hashing` 降级）；`embedder.type` 默认值在模型存在时 onnx、缺失时是否自动降级由你拍板（自动降级有「静默变假」风险，倾向 fail-fast + 指路）。
4. **安全收口**：`IRIS_API_KEY` 未设置时启动打 WARN「鉴权关闭，仅限本地」；README 部署一节写清生产前 checklist（设 key、收 actuator、改 compose 密码）。
5. **测试起步包**（P0-5 的最小满足）：优先覆盖 5 个安全核心——授权交集裁剪、语义缓存集合值不模糊、KeyStrategy 键形态、版本围栏判定、CDC 事件解析（RESP2/3 分流）。单测不依赖真实 Redis 的用 Testcontainers，起步约 5-8 个测试类。
